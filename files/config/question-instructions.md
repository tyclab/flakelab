Use flakelab-questions `ask_question` for decisions. The question must stand alone:
target and decision first; any recommendation is brief and optional. Nonessential
validation details belong in context, which is inbox-only. Prefer two action
labels of 1-3 words, aiming for 20 characters or fewer ("Merge and deploy", "Keep
open"), recommended first. Put the target in the question instead of repeating it
in each label.
Wait for the first answer before dependent work, even if backgrounded. If
unavailable, cancelled or expired, ask in chat; timeout is not consent. Use native
flows for tool permissions.
